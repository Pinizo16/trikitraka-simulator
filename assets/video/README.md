# Gameplay Video

Place the gameplay video at:

`assets/video/gameplay.mp4`

Recommended export:

- MP4 container
- H.264 video
- 1080p or 720p
- Short gameplay-focused edit
- No Roblox Studio or desktop capture

GitHub supports MP4 video uploads. For an inline player in a README, GitHub-hosted video attachment URLs are the reliable option; a normal repository-relative MP4 path should be treated as a file asset rather than relying on README video playback.
